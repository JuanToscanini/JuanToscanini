# Sobre mí:
Soy un desarrollador en formación constante, actualmente cursando el último tramo de la **Tecnicatura Universitaria en Programación** en la UTN FRCU.

- 🔨 Me especializo en desarrollo web **full-stack** con React y Node.js, con experiencia en proyectos reales tanto individuales como en equipo.
- ☕ También trabajo con **Java** (Spring Boot, Spring Security) y aplico principios SOLID y patrones de diseño (Adapter, Decorator, Facade, Observer).
- 🗄️ Experiencia con bases de datos relacionales (**PostgreSQL, MySQL, MariaDB**) y no relacionales (**MongoDB**), incluyendo migraciones con Flyway.
- 📊 Formación en **análisis de datos** con Python y Power BI, aplicando algoritmos de ML (Random Forest, K-Means, PCA).
- 🚀 Deployé proyectos en **Vercel + Render**, con pipelines CI/CD usando **GitHub Actions**.
- 📫 Podés contactarme en: **jmtoscanini@gmail.com**
